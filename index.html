How to join

四步进服

第一次来？照着做就好。

01

下载文件

上面下载客户端 ZIP，再下载 PCL 或 HMCL。安卓玩家下载 FCL，手机端还在测试中。

02

导入整合包

在启动器里导入 ZIP，保留版本名「神秘时代社区移植」。电脑端选择 Java 21。

03

连接服务器

用正版或离线账号进入游戏，固定使用同一个昵称，添加地址 a.mc1.top:40000。

04

首次注册

第一次输入 /reg 密码（6–30 位）；以后需要登录时输入 /l 密码。密码可别忘啦。

同昵称、同 IP 七天内可自动登录；换 IP 或到期后要重新输入密码。卡住了就把错误截图和日志发到群里，我们一起看看。
